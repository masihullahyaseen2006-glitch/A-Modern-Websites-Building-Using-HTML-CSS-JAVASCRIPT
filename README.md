A Modern Design of Website
FORMA is a modern, responsive landing page for an independent digital studio. It showcases the studio's work, capabilities, and approach through a dark editorial design with animated 3D-inspired visuals.
- Responsive layouts for desktop and mobile
- CSS 3D-inspired hero artwork and project illustrations
- Mobile navigation menu
- Filterable selected-work gallery
- Scroll-triggered reveal animations
- Interactive project-card hover effects
- Reduced-motion support for accessibility
